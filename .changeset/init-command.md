Add `jfdevelops init` to adopt an existing project: confirm detected targets, choose skills from installed packages, review every planned change with diffs and conflict decisions, then install skill copies for each agent, maintain a managed skill list in `AGENTS.md` and pointers in existing agent instruction files, and record the setup in `jfdevelops.json`. Cancelling before confirmation writes nothing, and repeat runs report when the project is already up to date.
