Offer a Monorepo option when `jfdevelops create` makes an app. It creates a private workspace root with shared formatting and linting, the app in its own package under `apps/`, a configurable namespace for package names, configurable app and library directories, and a root build script for pnpm, npm, yarn, and bun. `create` now also shows the folder layout it will write as a tree before you confirm.
