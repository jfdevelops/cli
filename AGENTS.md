# Project agent instructions

These convention skills are required. Read them before the corresponding work:

- Naming or renaming files, symbols, packages, or APIs: [.agents/skills/jf-naming-conventions/SKILL.md](.agents/skills/jf-naming-conventions/SKILL.md).
- Implementing or reviewing code: [.agents/skills/jf-coding-conventions/SKILL.md](.agents/skills/jf-coding-conventions/SKILL.md).
- Any Git decision, including initialization, branch names, commits, and PRs: [.agents/skills/jf-git/SKILL.md](.agents/skills/jf-git/SKILL.md). Read the current repository conventions before applying its shared defaults.

Read relevant repository instructions as well. These skills do not authorize commits, pushes, publishing, or deployments. Preserve existing user changes.

Read CONTRIBUTING.md before changing shared conventions or repository tooling.
